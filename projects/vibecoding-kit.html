덤 · 스킬 묶음 설치 문구

Claude Code 설치를 마친 뒤 첫 대화에 붙여 넣으면, AI가 쓰는 글자 양(토큰)을 아끼고 지나치게 복잡한 코드를 막아 주는 추가 기능(스킬) 6종(Caveman, Ponytail, token-efficiency, strategic-compact, token-compact, context-optimization)을 설치해 주는 문구입니다. 공식 저장소 확인 → 기존 설정 백업 → 안전하게 합치기 → 확인 순서로 진행하고, 다음 대화부터 자동으로 적용됩니다.

  • claude_code_skills_bundle_setup_prompt.md — 내용 전체를 복사해 Claude Code에 붙여 넣기
기능 자세히
  • Windows — 윈도우 기본 설치 도구(winget)로 Git과 VS Code(오른쪽 클릭 "Code로 열기" 메뉴 포함)를 설치하고, Claude Code와 VS Code 추가 기능(Claude Code, Live Server)까지 한 번에 설치. 이미 있는 것은 건너뛰고, 끝에 빠진 게 없는지 점검
  • 관리자 권한 없이 일반 사용자로 실행해 내 계정에 설치. 관리자 승인 창은 Git 설치 때 한 번만 뜸
  • Git에 쓸 이름·이메일 설정과 작업 폴더(문서\vibe-coding) 만들기까지 처리해, 워크북 1~2장을 막힘 없이 시작
  • 이미 설치된 컴퓨터에서는 설치를 건너뛰고 VS Code와 Claude 로그인 창만 바로 띄움. 다음부터는 같은 실행.bat이 바로가기 역할
  • 설정 문구(한국어로 답하기, 가장 간단한 방법 먼저, 되돌리기 어려운 작업 전엔 물어보기, 실행해서 확인하기)를 자동으로 클립보드에 복사
  • Mac — VS Code가 있는지 확인하고, Git(Command Line Tools)·Claude Code·추가 기능 설치와 작업 폴더(문서/vibe-coding) 만들기까지 자동
  • 자동으로 할 수 없는 로그인 단계와, 설치 도구가 없을 때·보안 경고가 뜰 때·압축을 안 풀고 실행했을 때 같은 실패 사례를 사용법.txt와 PDF 안내서에 정리
남은 문제와 다음 할 일
  • Mac은 VS Code를 직접 설치해야 합니다(Homebrew를 이용한 자동 설치는 아직 없음).
  • 공식 서명이 없는 설치 파일이라 Windows SmartScreen·macOS Gatekeeper 보안 경고가 뜹니다. 안내문으로 넘어가는 방법을 알려 드리고 있습니다.
