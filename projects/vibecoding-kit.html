바이브코딩 설치 키트

전체 폴더 다운로드 (ZIP · 111KB) ↓

VS Code도 Claude Code도 처음인 사람이 "실행.bat" 더블클릭 한 번으로 설치를 마치고, 첫 대화에 붙여 넣을 설정 프롬프트까지 클립보드에 받아 바로 바이브코딩을 시작하게 만든 설치 패키지.

Main Features

  • Windows: 관리자 권한으로 자동 재실행 후 winget으로 Git·VS Code를 설치하고, Claude Code 공식 설치 스크립트와 VS Code 확장까지 한 번에 설치
  • 이미 설치된 PC에서는 설치 단계를 건너뛰고 VS Code와 Claude 로그인 창만 바로 띄움 — 다음부터는 같은 실행.bat이 런처 역할
  • 설정 프롬프트(한국어 답변, 가장 간단한 방법 우선, 되돌리기 어려운 작업 전 확인, 실행 검증)를 자동으로 클립보드에 복사
  • Mac: VS Code·Node.js 설치 여부를 확인하고, 확장 설치와 바탕화면 연습 폴더(my-first-app) 생성까지 자동화
  • 자동화할 수 없는 로그인 단계와 winget 미설치, SmartScreen 경고, 압축 안 풀고 실행 같은 실패 사례를 사용법.txt와 PDF 가이드에 정리

Add-on · 스킬 번들 설치 프롬프트

Claude Code 설치를 마친 뒤 첫 대화에 붙여 넣으면, 토큰 절약·과설계 방지 스킬 6종(Caveman, Ponytail, token-efficiency, strategic-compact, token-compact, context-optimization)을 공식 저장소 확인 → 설정 백업 → 안전 병합 → 검증 순서로 설치하고 다음 세션부터 자동 적용되게 만드는 프롬프트.

  • claude_code_skills_bundle_setup_prompt.md — 내용 전체를 복사해 Claude Code에 붙여 넣기
