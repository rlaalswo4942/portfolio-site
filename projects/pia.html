Pia — 음성 어시스턴트

GitHub 링크 추가 예정

말 한마디로 대기 상태에서 바로 명령을 처리하는 상시 대기형 음성 비서를 만들다가, 로컬 LLM 구축의 한계에 부딪혀 잠시 멈춰 세웠다.

Main Features

  • 웨이크워드("피아야") 인식으로 상시 대기, 호출 즉시 반응 — 상태머신은 IDLE→ACTIVE→PROCESSING→IDLE(8초 타임아웃)
  • 웨이크워드→STT(Whisper)→로컬 LLM(Ollama, 자체 파인튜닝 모델 pia-ko)→TTS 파이프라인
  • 설정을 8개 Block(System/WakeWord/LLM/TTS/STT/Translation/Memory/Learning/Hub) 클래스로 관리 — 새 기능은 새 Block 추가로 확장
  • 자체 번역 모듈(4개 언어↔한국어)을 내장해 다국어 대응
  • 대화 데이터를 지속 수집해 LoRA로 개인화 모델을 파인튜닝하는 게 장기 목표 — "외부 클라우드 API는 코드 짜는 도구일 뿐, Pia의 두뇌는 오직 로컬 Ollama"라는 원칙

마이크 선정기(選定記)

인식률을 잡기 위해 마이크를 세 번 바꿨다: 기본 인덱스가 무신호라 실측으로 맞는 인덱스를 찾아 고정 → 원거리 인식과 이어폰 소리가 마이크로 재입력되는 문제를 동시에 잡으려고 골전도 이어폰(Shokz OpenFit)으로 최종 교체. 그 다음엔 대역통과 필터+에코제거+AGC+노이즈 게이트로 4단계 전처리 파이프라인을 만들었는데, 노이즈 게이트가 오히려 먼 목소리까지 막아버려 억제 강도를 다시 낮췄다 — 잡음을 지우는 것과 목소리를 지우는 것 사이에서 계속 저울질한 과정이었다.

Known Issues · Next Steps

  • 로컬 LLM 구축 수준으로는 원하는 AI 제작 품질에 한계가 있어 개발을 보류함
  • 추후 LLM API를 활용하거나, SLM만으로 운영 가능한 수준까지 업그레이드할 예정
  • 마이크 수음 문제로 인식이 잘 안 되는 현상이 있어 이 부분을 중점적으로 개발할 예정
  • 과거 PC 제어 모듈에 음성 명령이 쉘 명령으로 그대로 전달될 수 있는 보안 취약점이 있었음 — shell=False 전환 등으로 수정 완료, 이후 "새 실행 경로를 추가할 땐 반드시 이 패턴을 재사용한다"는 원칙으로 남김
  • 별도 작업 사본(Pia_test)에 반영된 변경이 본 저장소에 완전히 합쳐졌는지 아직 확인 못한 상태로 남아있음
