Pia — 음성 어시스턴트

GitHub 링크 추가 예정

"피아야" 하고 부르면 깨어나, 말로 시킨 일을 처리하는 컴퓨터용 음성 비서입니다. 핵심인 'AI 두뇌'를 내 컴퓨터 안에서만 돌리려다 품질의 벽에 부딪혀, 지금은 잠시 멈춰 둔 상태입니다.

한눈에 보기

무엇인가요

윈도우 컴퓨터에 늘 켜져 있다가, 이름을 부르면 말을 알아듣고 대답하거나 일을 대신하는 음성 비서 프로그램입니다. 휴대폰의 시리·빅스비 같은 것을 컴퓨터용으로 직접 만든 것이라고 보면 됩니다.

무엇이 다른가요

대화 내용을 외부 회사 서버로 보내지 않고, 내 컴퓨터 안에 둔 AI만으로 생각하고 답하게 하는 것이 원칙이었습니다. 쓸수록 내 말투와 습관에 맞춰지는 '나만의 비서'가 장기 목표였습니다.

어떻게 움직이나요

① "피아야"를 기다림 → ② 부르면 듣기 시작 → ③ 말을 글자로 바꿈 → ④ AI가 뜻을 이해하고 답을 만듦 → ⑤ 답을 목소리로 읽어 줌. 8초 동안 말이 없으면 다시 기다리는 상태로 돌아갑니다.

지금 상태 · 보류

내 컴퓨터 안에서 돌릴 수 있는 AI로는 원하는 품질이 나오지 않아 멈췄습니다. 외부 AI 서비스를 쓰거나, 작지만 쓸 만한 AI로 바꾸는 방향을 찾고 있습니다.

주요 기능

  • 이름으로 깨우기 — "피아야"라는 호출어를 들으면 바로 반응합니다. 평소에는 '기다림 → 듣기 → 처리 → 다시 기다림' 네 단계를 오갑니다.
  • 말 → 글자 → 생각 → 목소리 — 들은 말을 글자로 바꾸고(Whisper), 내 컴퓨터 속 AI(Ollama, 한국어용으로 직접 조정한 pia-ko 모델)가 답을 만든 뒤, 다시 사람 목소리로 읽어 줍니다.
  • 블록처럼 끼워 넣는 구조 — 호출어·AI·목소리·번역·기억·학습 같은 설정을 영역별 묶음(Block)으로 나눴습니다. 새 기능을 넣을 때 기존 부분을 건드리지 않고 블록 하나만 더 붙이면 됩니다.
  • 번역 내장 — 외국어 4개와 한국어 사이를 오가는 번역 기능을 자체적으로 갖고 있습니다.
  • 나에게 맞춰지는 AI (장기 목표) — 나눈 대화를 계속 모아 AI를 내 말투에 맞게 조금씩 더 가르치는(LoRA 파인튜닝) 것이 목표입니다. 원칙은 "외부 AI 서비스는 코드를 짤 때 돕는 도구일 뿐, 피아의 두뇌는 내 컴퓨터 안의 AI만 쓴다"였습니다.

마이크를 고른 이야기

음성 비서는 말을 잘 알아듣는 것이 먼저라 마이크를 세 번 바꿨습니다. 처음에는 컴퓨터가 기본으로 고른 마이크에서 아무 소리도 들어오지 않아, 하나씩 직접 녹음해 보며 제대로 된 마이크 번호를 찾아 고정했습니다. 다음 문제는 두 가지였습니다. 멀리서 말하면 못 알아듣고, 이어폰에서 나온 피아 목소리가 다시 마이크로 들어가 자기 말을 자기가 듣는 것이었습니다. 둘을 함께 풀려고 귀를 막지 않는 골전도 이어폰(Shokz OpenFit)으로 바꿨습니다.

그다음엔 소리를 4단계로 다듬는 과정(필요한 음역만 남기기 → 메아리 지우기 → 소리 크기 자동 맞추기 → 작은 잡음 막기)을 만들었습니다. 그런데 마지막 잡음 막기가 너무 세서 멀리서 말한 진짜 목소리까지 잘라 냈고, 그래서 강도를 다시 낮췄습니다. 잡음을 지우는 것과 목소리를 지키는 것 사이에서 계속 균형을 맞춘 과정이었습니다.

남은 문제와 다음 할 일

  • 내 컴퓨터 안에서 돌릴 수 있는 AI(로컬 LLM)로는 원하는 품질이 나오지 않아 개발을 멈췄습니다.
  • 앞으로는 외부 AI 서비스(LLM API)를 쓰거나, 작은 AI(SLM)만으로도 쓸 만한 수준까지 끌어올리는 방향으로 다시 시작할 예정입니다.
  • 마이크가 소리를 제대로 받지 못해 잘 못 알아듣는 문제를 가장 먼저 다룰 계획입니다.
  • 보안 문제 하나를 고쳤습니다. 예전에 컴퓨터를 조작하는 기능에서, 말로 한 명령이 컴퓨터 명령어로 그대로 실행될 수 있는 위험이 있었습니다. 명령을 그대로 넘기지 않는 안전한 방식(shell=False)으로 바꿨고, 새 실행 기능을 넣을 때는 반드시 이 방식을 쓰기로 정했습니다.
  • 따로 떼어 실험하던 복사본(Pia_test)의 변경 내용이 본래 코드에 모두 합쳐졌는지 아직 확인하지 못했습니다.

어려운 말 풀이

호출어(웨이크워드)
비서를 깨우는 말. "시리야", "하이 빅스비" 같은 것입니다.
STT · TTS
말을 글자로 바꾸는 기술(Speech-to-Text) · 글자를 목소리로 읽는 기술(Text-to-Speech).
LLM
아주 많은 글을 배워 사람처럼 문장을 이해하고 만들어 내는 AI. ChatGPT 같은 서비스의 핵심 부품입니다.
로컬 LLM
회사 서버가 아니라 내 컴퓨터 안에서 돌리는 LLM. 대화가 밖으로 나가지 않는 대신, 내 컴퓨터 성능만큼만 똑똑해집니다.
SLM
작은 언어 모델. LLM보다 가볍고 빠르지만 덜 똑똑합니다.
파인튜닝 · LoRA
이미 만들어진 AI를 내 자료로 조금 더 가르쳐 원하는 쪽으로 맞추는 것 · 그 작업을 가볍게 하는 방법.
API
다른 프로그램이나 서비스의 기능을 빌려 쓰는 창구.
