스터디 프레임 — 학습 사이트 엔진

GitHub 링크 추가 예정

강의 자료를 넣으면, 바로 공부할 수 있는 사이트가 나온다 — 내용만 바꿔 과목마다 같은 엔진을 쓴다.

Main Features

  • 원고 마크다운에서 단원·섹션·읽음 체크리스트·목표 자가점검을 자동 생성, 홈 카드에 읽음 진도와 정답률 표시
  • 필기(펜·형광펜·가림펜·지우개)와 포스트잇 — 위치를 섹션 기준 비율로 저장해 기기가 달라도 같은 자리에 표시
  • 태블릿용 펜 전용 모드: 손가락은 스크롤·버튼, 펜은 필기. 두 손가락 탭 실행취소, 세 손가락 탭 다시실행
  • 연습문제(단원별·전 범위·오답 다시 풀기, 해설·출처), 코드 빈칸형 문제, 유형별 모의고사, 용어 사전
  • 이름 로그인으로 개인별 기록, 동기화 코드로 기기 간 실시간 동기화(Vercel + Neon 서버 하나를 모든 사이트가 공유)
  • "스터디_프레임으로 OO 학습 사이트 만들어" 한마디로 새 사이트를 만드는 Claude 스킬까지 함께 관리
