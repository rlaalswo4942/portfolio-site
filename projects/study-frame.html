무엇인가요

정리한 강의 원고와 문제만 넣으면 단원별 노트·필기·포스트잇·연습문제·모의고사가 갖춰진 공부 사이트를 만들어 주는 '틀(엔진)'입니다.

왜 만들었나요

처음엔 AI 해커톤을 준비하려고 학습노트 사이트 하나를 만들었습니다. 다른 과목에도 쓰고 싶어서, 과목과 상관없는 공통 부분을 떼어 냈습니다.

어떻게 쓰나요

사이트에 들어가 이름으로 로그인하면, 읽은 곳 체크·필기·문제 풀이 기록이 내 것으로 저장됩니다. 동기화 코드를 넣으면 휴대폰·태블릿·컴퓨터에서 같은 기록이 이어집니다.

지금 상태 · 운영 중

아래 4개 학습노트 사이트가 이 틀로 돌아가고 있습니다.

주요 기능

  • 원고(마크다운 문서)에서 단원·소단원·읽음 체크리스트·학습 목표 자가 점검을 자동으로 만듦. 첫 화면 카드에 얼마나 읽었는지, 문제를 얼마나 맞혔는지 표시
  • 필기(펜·형광펜·가림펜·지우개)와 포스트잇. 위치를 '이 문단의 몇 % 지점'처럼 저장해서, 화면 크기가 다른 기기에서도 같은 자리에 표시
  • 태블릿 펜 전용 모드: 손가락은 화면 넘기기·버튼 누르기, 펜은 필기. 두 손가락으로 톡 치면 되돌리기, 세 손가락이면 다시 하기
  • 연습문제(단원별·전체 범위·틀린 문제 다시 풀기, 해설과 출처 포함), 코드 빈칸 채우기 문제, 유형별 모의고사, 용어 사전
  • 이름 로그인으로 사람마다 따로 기록. 동기화 코드로 기기 사이 실시간 동기화(모든 사이트가 Vercel + Neon 서버 하나를 함께 씀)
  • "스터디_프레임으로 OO 학습 사이트 만들어"라고 한마디 하면 새 사이트를 만들어 주는, Claude용 작업 설명서(스킬)도 함께 관리

틀을 떼어 낸 과정

처음엔 AI 해커톤 대비용 학습노트 하나였습니다. 다른 과목에도 쓰고 싶어서, 과목마다 달라지는 문구와 원고 읽는 규칙은 설정 파일(content.js) 하나에 모으고, 나머지 엔진 파일은 모든 사이트에서 똑같이 유지하는 구조로 바꿨습니다.

덕분에 한 사이트에서 고친 기능을 다른 사이트에도 그대로 옮길 수 있습니다. 예를 들어 형광펜이 글자를 덮어 잘 안 보이던 문제를, 형광펜을 글자와 섞이는 '곱하기' 방식의 별도 층에 칠하도록 고쳐 모든 사이트에 함께 반영했습니다. 사이트마다 저장 이름을 다르게 두어, 동기화 서버를 함께 써도 기록이 섞이지 않습니다.
