지금 상태 · 진행 중

영어는 꽤 정확하고, 중국어·일본어는 보완 중입니다.

기능 자세히
  • 휴대폰 안에서만 번역 — 서버 없이 휴대폰 안에서 AI를 돌립니다(Flutter로 앱을 만들고, ONNX Runtime으로 AI를 실행).
  • 세 가지 입력 — 글자 입력, 음성, 사진 속 글자 읽기(OCR)를 모두 지원합니다.
  • 영어를 다리로 쓰기 — 한국어→일본어처럼 곧바로 번역하는 AI가 없는 언어 쌍은 '한국어→영어→일본어'로 두 번 거쳐 번역합니다.
  • 돈 받고 써도 되는 AI만 사용 — 번역 AI는 상업적으로 써도 되는 사용 조건(Apache-2.0, MIT 라이선스)인 것만 골랐습니다. 품질이 더 좋아도 비상업용으로만 허락된 모델(NLLB 등)은 뺐습니다.
  • 번역 기록 재활용 — 번역 기록을 중앙 데이터베이스로 보내 Pia를 가르치는 자료로 다시 씁니다.
  • 자동 제작 — 번역 AI를 휴대폰용으로 바꾸는 일부터 설치 파일을 만들어 올리는 일까지 GitHub Actions가 자동으로 처리합니다.
버그를 잡은 기록 (BUG-001~004)
  • "real real real…"이 끝없이 반복됨 — 같은 말을 되풀이하지 못하게 막는 장치가 없었습니다. 같은 단어 묶음의 반복을 금지하고, 반복하면 점수를 깎는 설정을 넣어 해결했습니다.
  • "안녕하세요"가 "여호와하나님"으로 번역됨 (BUG-002) — AI는 단어를 번호로 바꿔 읽는데, 앱이 다른 번호표를 쓰고 있었습니다. 사전 두 권의 쪽수를 섞어 찾은 셈이라 전혀 다른 단어가 나왔습니다. 그래도 결과가 '한국어처럼' 보여서 한동안 번역이 되는 줄 알고 놓쳤습니다.
  • "Hi Hi Hi…"가 끝없이 반복됨 (BUG-004) — 처음에는 AI를 휴대폰용으로 가볍게 줄이는 과정(양자화)에서 품질이 떨어진 탓이라 생각해 반복 억제만 더 세게 걸어 덮었습니다. 나중에 줄이기 전 원본으로 똑같이 해 보니, 진짜 원인은 문장 끝에 '여기서 끝'이라는 표시(EOS 토큰)를 붙이지 않은 것이었습니다. 붙이자마자 정상적으로 끝났습니다. 교훈: 원인을 찾을 땐 항상 원본으로 먼저 재현해서, 줄이는 과정의 문제인지 코드 문제인지부터 가를 것.
  • 영어→한국어 예비 번역 AI의 품질이 너무 나빠("hello world"가 알아볼 수 없는 결과로 나옴) 같은 사용 조건(Apache-2.0)의 다른 AI로 바꿨습니다.
남은 문제와 다음 할 일
  • 영어는 어느 정도 정확하지만, 중국어·일본어는 정확도가 많이 떨어집니다.
  • 휴대폰에 들어 있는 기본 언어 자료만으로는 부족해 보완 방법을 찾고 있습니다.
  • 실제 휴대폰(갤럭시 S22)으로 마지막 확인을 하다 멈췄습니다. 컴퓨터에서 휴대폰으로 영어 문장을 자동 입력해도 실제로 입력되지 않는 현상이 있었고(키보드가 한글 상태였을 가능성), 다시 시작할 지점만 문서로 남겨 두었습니다.
