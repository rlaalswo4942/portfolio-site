Pia-Translate

GitHub 링크 추가 예정

인터넷도, PC도 없이 폰 안에서 완전히 로컬로 동작하는 번역 앱 — 언어별 정확도 편차를 줄이는 게 지금 과제다.

Main Features

  • Flutter로 제작한 크로스플랫폼 오프라인 번역 앱
  • ONNX Runtime으로 기기 내 로컬 추론 처리
  • 서버 연결 없이 완전 오프라인 동작
  • Pia의 다국어 기능을 위해 별도로 분리해 발전 중

Known Issues · Next Steps

  • 영어는 어느 정도 정확하지만, 중국어·일본어는 정확도가 많이 떨어지는 편
  • 폰 자체 내장 언어팩만으로는 정확도가 부족해 이를 보완할 방안을 모색 중
