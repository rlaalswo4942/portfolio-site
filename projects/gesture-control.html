핸드모션

GitHub 링크 추가 예정

마우스도 키보드도 없이, 손짓만으로 명령을 내린다 — 아직 개발 중인 프로그램.

Main Features

  • MediaPipe로 손 랜드마크를 실시간 인식해 PPT/PDF 슬라이드 제어·마우스 조작·단축키 실행·방사형 메뉴 호출까지 지원
  • 상태머신: IDLE → ACTIVE(손바닥 유지) → 등록 흐름(카운트다운→녹화→저장) / 마우스 모드(검지) / 방사형 메뉴(주먹)로 분기
  • 커스텀 제스처는 30프레임으로 리샘플링해 저장, 이후 프레임당 평균 오차로 최근접 템플릿 매칭
  • 제스처 실행 로그를 별도 스레드로 중앙 DB에 비동기 기록 — 카메라 루프가 DB 쓰기 때문에 밀리지 않도록 분리
  • PyInstaller 배포용 exe와 스크립트 실행 두 환경 모두 지원

Known Issues · Next Steps

  • 아직 개발 중인 프로그램 — 인식 정확도와 동작 보정 등 보완할 점이 있음
  • 커스텀 제스처 슬롯 10개가 전부 미설정 상태로 남아있음
  • alias(제스처가 다른 제스처를 가리키는 기능)가 서로를 순환 참조하면 무한루프가 될 수 있어, 방문한 이름을 기록해두고 다시 만나면 끊는 방식으로 방지해둠

하위 리서치 — 손 추적 3D 스컬핑

마우스나 태블릿 대신 손의 움직임 자체를 3D 조형 입력으로 쓰는 인터랙션 아이디어. 핸드모션의 손 추적 작업을 확장하는 하위 개념으로, 다중 카메라 기반 삼각측량으로 깊이와 손가락 가려짐 문제를 푸는 방향을 조사했다. 맨손/장갑/마커/가상 마커 등 추적 방식을 비교 검토한 단계이며, 별도 프로젝트가 아니라 핸드모션의 리서치 갈래로 취급한다.
