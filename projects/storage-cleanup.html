PC 저장공간 정리

GitHub 링크 추가 예정

컴퓨터 저장 공간을 잡아먹는 쓸모없는 파일·중복 파일·큰 미디어 파일을 찾아 줍니다. 단, 지울지 말지는 언제나 사용자가 정합니다.

한눈에 보기

무엇인가요

윈도우 컴퓨터의 모든 드라이브(C:, D: 등)를 살펴보고, 정리할 만한 파일 목록을 보여 주는 프로그램입니다.

왜 필요한가요

용량이 부족할 때 무엇을 지워도 되는지 알기 어렵고, 잘못 지우면 프로그램이 망가질 수 있습니다. 그래서 프로그램은 '찾아 주기'만 하고, 결정은 사람이 하게 했습니다.

어떻게 쓰나요

① 찾아보기(이때는 아무것도 바꾸지 않음) → ② 목록에서 지울 것만 체크 → ③ 실행. 지운 파일은 먼저 '격리함'으로 옮겨져 되살릴 수 있습니다.

지금 상태 · 진행 중

기능은 다 만들었고, 무엇을 '쓸모없다'고 볼지 판단 기준과 전체 시험이 남았습니다.

주요 기능

  • 모든 고정 드라이브에서 쓸모없는 임시 파일, 오래된 큰 파일, 중복된 설치 파일, 사진·영상 같은 미디어 파일을 찾음
  • '찾아보기(시험 실행) → 사용자가 체크 → 실제 실행' 2단계. 찾아보는 동안에는 디스크를 절대 바꾸지 않음
  • 5겹 안전장치: ① 윈도우 시스템 폴더는 아예 제외 ② 설치된 프로그램은 윈도우 설치 목록을 확인해 자동 보호 ③ 항상 시험 실행 먼저 ④ 지금 쓰고 있는 파일은 자동 보호 ⑤ 중복 찾기는 설치 파일 종류로만 한정
  • 지운 파일은 격리함에서 되살릴 수 있고, 완전히 지우려면 "삭제확인"이라고 직접 입력해야 함
  • 찾는 작업을 화면과 따로 돌려서 오래 걸려도 창이 멈추지 않음. 체크 칸은 한 번만 눌러도 바로 바뀜

만들면서 부딪힌 문제들

이 도구는 윈도우에 기본으로 들어 있는 PowerShell로 만들었는데, 이 언어만의 이상한 동작에 여러 번 걸렸습니다. 빈 목록을 돌려주면 받는 쪽에서는 '아무것도 없음(null)'으로 바뀌어 버리고, 항목이 딱 1개인 목록을 돌려주면 목록이 아니라 낱개 하나로 풀려 버려 프로그램이 헷갈렸습니다(앞에 쉼표를 붙여 감싸야 목록 그대로 전달됩니다).

체크 칸도 처음엔 첫 번째 클릭은 '선택'만 되고 두 번째 클릭에야 체크됐습니다. 칸을 편집 모드로 바꾸는 방식 대신, 늘 살아 있는 일반 체크 칸을 쓰도록 바꿔 해결했습니다. 이렇게 같은 문제를 다시 겪지 않기 위한 원칙 9가지를 정리해 두었습니다.

남은 문제와 다음 할 일

  • 무엇이 정말 쓸모없는 파일인지, '비어 있다'고 보이지만 실제로는 필요한 경우 등 세부 판단 기준을 아직 다 알지 못합니다.
  • 관리자 권한이 없으면 일부 파일은 사용자가 직접 확인하고 지워야 하는 문제가 있어 보완할 예정입니다.
  • 탭마다의 세부 동작은 기능은 다 만들었지만 전체 시험이 더 필요합니다.
