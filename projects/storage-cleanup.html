정크·중복·미디어 파일을 찾아서, 지울지 말지는 항상 사용자가 정한다.

Main Features

  • 모든 고정 드라이브를 대상으로 정크/오래된 대용량/중복 설치파일/미디어 파일 스캔
  • "스캔(드라이런) → 사용자 체크 → 실제 실행"의 2단계 구조 — 스캔 자체는 절대 디스크를 바꾸지 않음
  • 5중 안전장치: 시스템 경로 화이트리스트 제외, 레지스트리 기반 설치 프로그램 자동 보호, 드라이런 우선, 사용 중 파일 자동 보호, 중복 탐지는 설치파일류로만 한정
  • 격리함에서 복원하거나 "삭제확인" 문구를 직접 입력해야 영구 삭제
  • 별도 Runspace에서 완전 비동기로 스캔해 GUI가 멈추지 않음, 체크박스는 한 번 클릭으로 바로 토글

PowerShell의 함정들

이 도구를 만들며 겪은 PowerShell 특유의 함정이 많았다: 빈 배열을 그냥 반환하면 호출부에서 null로 취급되고, 항목이 딱 1개인 컬렉션을 반환하면 자동으로 낱개로 풀려버려 타입이 깨진다(콤마 연산자로 감싸야 진짜 컬렉션으로 반환됨). 체크박스도 처음엔 첫 클릭이 선택만 되고 토글은 두 번째 클릭에야 됐는데, 셀 편집 방식 대신 항상 살아있는 일반 컨트롤로 바꿔서 해결했다. 이런 재발방지 원칙 9가지를 정리해두었다.
