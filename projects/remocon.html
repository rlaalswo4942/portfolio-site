자주 쓰는 개발 프로그램을, 단축키 하나로 바로 켠다.

Main Features

  • Pia·STT·바탕화면 정리처럼 개발 중인 여러 프로그램을 한 화면에서 슬라이드 스위치로 켜고 끔
  • config.json에 프로그램(실행 명령·매칭 키워드·종료 방식)만 추가하면 코드 수정 없이 확장
  • 종료 방식은 프로세스 강제 종료와 예약 작업 토글(백그라운드 감시자가 있는 프로그램용) 두 가지로 구분 처리
  • 디스코드 채널 목록을 참고한 다크 테마 — 색상 코드·창 크기(492×514px)까지 승인받아 고정값으로 못박아둠
