프로그램 리모컨

GitHub 링크 추가 예정

자주 쓰는 개발 프로그램들을 TV 리모컨처럼 한 화면에서 켜고 끕니다. 단축키 하나로 바로 띄울 수 있습니다.

한눈에 보기

무엇인가요

만들고 있는 여러 프로그램(Pia, STT, 바탕화면 정리 등)을 한 창에 모아 두고, 스위치를 밀어 켜고 끄는 실행기입니다.

왜 필요한가요

프로그램이 늘어날수록 각각 폴더를 찾아 실행하고 끄는 일이 번거로워집니다. 한곳에서 관리하려고 만들었습니다.

어떻게 쓰나요

단축키로 리모컨 창을 띄우고, 원하는 프로그램 옆 스위치를 켜거나 끕니다.

지금 상태 · 완성

디스코드처럼 어두운 색 화면으로 디자인까지 확정했습니다.

주요 기능

  • Pia·STT·바탕화면 정리처럼 개발 중인 여러 프로그램을 한 화면에서 밀어서 켜고 끄는 스위치로 관리
  • 설정 파일(config.json)에 프로그램 정보(실행 명령, 찾을 때 쓰는 이름, 끄는 방법)만 적으면 코드를 고치지 않고 새 프로그램 추가
  • 끄는 방법을 두 가지로 구분: 실행 중인 프로그램을 바로 끄기 / 뒤에서 계속 지켜보는 프로그램은 윈도우 예약 작업을 켜고 끄기
  • 디스코드 채널 목록을 참고한 어두운 화면. 색상 값과 창 크기(492×514px)까지 승인받아 고정해 둠

남은 문제와 다음 할 일

  • 리모컨과, 각 프로그램이 따로 가진 단축키 감시 기능을 함께 켜 두면 같은 단축키가 두 번 실행될 수 있습니다. 리모컨을 주로 쓸 때는 각 프로그램의 단축키 기능을 꺼 두기를 권합니다.

어려운 말 풀이

런처
여러 프로그램을 한곳에서 실행하게 해 주는 프로그램.
설정 파일
코드를 고치지 않고 프로그램 동작을 바꿀 수 있게 적어 두는 파일.
프로세스
실행 중인 프로그램 하나하나.
예약 작업
정해진 때 프로그램을 자동으로 실행해 주는 윈도우 기능(작업 스케줄러).
데몬
화면 없이 뒤에서 계속 돌아가며 기다리는 프로그램.
