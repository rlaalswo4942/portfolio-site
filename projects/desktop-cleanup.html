바탕화면 정리

GitHub 링크 추가 예정

바탕화면이 어지러워지면, 단축키 한 번으로 원래대로 돌아온다.

Main Features

  • Ctrl+Space→S 단축키로 바탕화면 파일을 확장자·용도별 폴더로 이동, 수동 GUI 정리와 자동 정리(예약 작업) 모드 제공
  • Assets + ProjectSettings 폴더를 가진 폴더는 "유니티" 프로젝트로 따로 분류
  • 휴지통·내 PC·작업 관리자 같은 시스템 아이콘은 제자리에 둔 채 나머지만 왼쪽 정렬
  • 정렬 후 자동 정렬은 끄고 그리드 맞춤은 다시 켜서, 이후 아이콘을 직접 옮겨도 튕기지 않고 칸에 맞춰 놓임

Windows 셸과 씨름한 부분

아이콘 한 개의 위치를 옮기는 일부터 막혔다. 바탕화면 리스트뷰는 탐색기 프로세스 소유라 일반적인 메시지 방식은 무시되고, COM의 IFolderView2::SelectAndPositionItems를 써야 했다. 흔히 알려진 플래그 값(0x08)이 아니라 0x80이어야 했고, 그리드 맞춤 비트가 켜져 있으면 API가 성공을 돌려줘도 실제로는 아무 일도 일어나지 않았다. 부팅 직후 단축키가 안 먹는 문제는 로그온 트리거를 20초 지연 + 재시도로, 예약 작업과 시작프로그램이 동시에 떠서 한 번 누르면 두 번 정리되던 문제는 이름 있는 뮤텍스로 단일 실행을 보장해 해결했다(2026-10-11). 검증은 탐색기를 재시작하지 않고 라이브 바탕화면에서 단계별로 했고, 탐색기 PID가 바뀌지 않는 것(크래시 없음)을 성공 기준으로 삼았다.
