Pia 학습 데이터베이스

GitHub 링크 추가 예정

Pia가 배우는 모든 음성·텍스트 데이터가 쌓이는 저장소.

Main Features

  • 음성 파일·텍스트·레이블 학습 데이터 저장 (Dataset/Entry/StoredFile 스키마, SHA-256로 중복 파일 감지)
  • Railway에 미러 DB를 구축해 외부 기기에서도 접속 가능
  • 전 프로젝트가 공용으로 쓰는 dev_logs(작업 로그)/dev_items(기능·버그·할일 트래커) 테이블도 함께 운영 — "백업해" 한마디로 여기에 기록이 쌓임
  • 다른 프로젝트가 이 DB에 연결할 때 그대로 복사해 쓰는 Python/TypeScript/Dart 클라이언트 템플릿 제공

가장 근본적이었던 사고

한때 로컬 작업 폴더가 "데이터베이스"와 "데이터베이스 (1)" 두 개로 갈라져, 같은 API를 각자 독립적으로 다시 만들고 있었다. git status만 보고 "동기화됐다"고 착각했던 게 원인 — 실제로는 origin에 옛날 버전만 올라가 있었고, 더 발전된 로컬 버전은 한 번도 push된 적이 없었다. git merge로 병합해 해결했고, 이후로는 "여러 기기/세션에서 작업할 땐 시작 전 항상 fetch 후 양방향 diff를 직접 확인한다", "폴더를 복제해서 병행 작업하지 않는다"는 원칙을 남겼다.
