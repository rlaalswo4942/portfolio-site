Pathlight

데모 링크 추가 예정 GitHub 링크 추가 예정

새 하드웨어를 깔지 않고, 기존 가로등만으로 사람이 지나가는 구간을 밝힌다.

Main Features

  • 출발지·목적지 기반 보행 경로 계산(OSRM)
  • 이동 경로 앞쪽 가로등을 순차 활성화, 지난 구간은 자동 복귀
  • 고장·깜빡임 등 시설 이상 신고 및 안전 인프라 지도 제공
  • 에너지 절감 시뮬레이션 포함

Data · Method · Validation · Limitation

Data

실제 OpenStreetMap 가로등 위치 데이터 사용. 하드웨어 제어는 미연결(시뮬레이션)

Method

사람 없는 시간 일괄 절전 대신, 실제 이동 경로에 맞춰 조명 상태를 NORMAL → PRE-ACTIVE → ACTIVE로 전환

Validation

기술·안전·법률·운영·비즈니스 5개 영역 조사 수행 (가로등 제어 가능성, 위치정보법, 학교 시설 관리 체계 등)

Limitation

실제 가로등 하드웨어 제어 연동 없음 · 다중 사용자 동시 이동 시 깜빡임 방지 로직은 검토 단계

Known Issues · Next Steps

  • 처음엔 바닥 센서로 실제 가로등을 제어하는 방향(ESP32 등)을 검토했으나, 설치비·승인 부담 때문에 "신규 하드웨어 설치 없이 기존 가로등과 무료 API만 쓴다"는 방향으로 피벗함 — README가 이 전환 이전 설계를 그대로 설명하고 있어 실제 코드(관리자 토글 기준)와 어긋난 상태
  • 가로등 위치는 실제 OpenStreetMap 데이터만 쓰고 없으면 0개로 정직하게 표시 — 처음엔 경로를 따라 합성 생성했다가 실제 데이터로 교체함
  • 기본 도보 경로 서버(router.project-osrm.org)의 "보행자용" 엔드포인트가 실은 차량 경로와 완전히 같은 값을 반환한다는 걸 직접 검증으로 발견 — 실제 보행자 속도 프로파일을 쓰는 FOSSGIS 서버로 교체
  • 긴급 조명 강제 활성화 버튼이 실제로는 그 기능을 호출하는 곳이 없어 동작하지 않는 죽은 코드 상태로 남아있음 — 아직 미수정
