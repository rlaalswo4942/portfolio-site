정애 — 로프 액션 심리 스릴러

GitHub 링크 추가 예정

119 특수구조대원 차진혁이 알츠하이머로 무너져가는 어머니 이정애의 무의식에 들어가, 로프로 기억과 신경망을 이어 붙이며 마지막 작별에 도달하는 2D 심리 스릴러 로프 액션 플랫포머.

Main Features

  • 기억 브릭을 밀거나 로프로 끌어 빈 뇌 공간을 채우면, 그 결과가 즉시 발판·벽·앵커·신경 통로로 바뀌어 다음 구역의 지형이 되는 퍼즐-액션 결합 구조
  • 좌클릭 하나로 발사·유지·회수하는 로프 조작에 오브젝트 견인·앵커 스윙·파괴·신경 전도·시한부 부유 앵커까지 5대 기믹 결합
  • 시냅스 관문을 통과할 때마다 진혁의 기억이 자동으로 소모되는 "하이패스 기억 결제" — 어머니를 복구할수록 주인공 자신의 감정 공감 능력이 무너짐
  • 누적 사망 횟수에 따라 3단계로 심화하는 환각 시스템. 체크포인트에서 일부만 완화되고 후반으로 갈수록 완전히 정상으로 돌아오지 않음
  • 초반 논리 퍼즐·통제감에서 후반 강제 스크롤·붕괴 지형·망각의 추격으로 뒤집히는 난이도 곡선이 곧 감정 곡선
  • 알츠하이머의 장기 진행과 급성 섬망을 구분해 다루고, 완치가 아니라 짧은 명료성과 작별로 끝나는 결말 설계

세계관 & 등장인물

  • 차진혁 (41, 119 특수구조대원) — 플레이어블 캐릭터. 현실에서 사람을 구조하던 로프를 무의식에서 기억과 신경망을 구조하는 도구로 사용
  • 이정애 (67) — 63~64세 무렵 발병한 조발성 알츠하이머로 수년간 진행. 무의식 세계의 주체
  • 한서연 (37, 아내) · 차도윤 (9, 아들) — 도윤의 8비트 로프 게임 규칙이 무의식 공간 튜토리얼에 투영됨
  • 5막 구조: 현실의 균열 → 첫 무의식 → 효과의 확인 → 자발적 희생 → 마지막 구조와 작별
