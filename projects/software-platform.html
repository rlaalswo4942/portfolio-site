직접 만든 프로그램을 '월 구독'으로 팔고 관리할 수 있는 웹사이트입니다. 시험용 사이트가 올라가 있어, 손님 계정으로 실제 흐름을 둘러볼 수 있습니다.

한눈에 보기

무엇인가요

넷플릭스가 영상을 구독으로 제공하듯, 프로그램을 구독해서 내려받아 쓰게 하는 판매·관리 웹사이트입니다.

누가 쓰나요

파는 사람(관리자)은 상품·가격·새 버전을 올리고, 쓰는 사람은 구독하고 내려받습니다. 설치된 프로그램은 이 사이트에 "계속 써도 되나요?"를 물어 확인합니다.

어떻게 움직이나요

매달 결제를 확인하고, 결제가 끊기면 경고를 3번 보낸 뒤 사용을 막습니다. 다시 구독하면 예전 자료를 되살려 줍니다.

지금 상태 · 데모 배포됨

시험용 사이트는 올라가 있지만, 실제 결제 연결은 아직이라 판매할 수 있는 단계는 아닙니다.

주요 기능

  • 핵심 흐름 — 매달 결제 확인 → 결제가 끊기면 3번 경고 후 사용 차단 → 다시 구독하면 기존 자료 복원
  • 상품마다 가격 방식 선택 — 무료 / 한 번 구매 / 구독. GitHub에 새 버전을 올리면 '안정판'과 '시험판(베타)'으로 자동 분류하고, 꼭 업데이트해야 할 때는 강제 업데이트 표시
  • 관리자용 화면 편집기 — 페이지의 요소를 클릭하면 옆 패널에서 바로 고칠 수 있음
  • 설치된 프로그램과 대화하는 창구(API) — 사용 자격 확인, 최신 버전 확인, 사용 기록 수집
  • 시험용 사이트 — Vercel과 Neon으로 올려 두어, 손님 계정으로 실제 서비스 흐름을 체험 가능

보안 점검 3번

스스로 세 번 보안 점검을 해서 모두 14건을 고쳤습니다.

  • 1차 (7건) — 허락되지 않은 폴더의 파일을 꺼내 볼 수 있는 구멍(경로 탐색), 비밀번호를 끝없이 시도할 수 있는 문제, 가입된 이메일인지 알아낼 수 있는 문제 등
  • 2차 (3건) — 응답에 엉뚱한 내용을 끼워 넣을 수 있는 문제(헤더 인젝션), 메모리가 조금씩 새는 문제 등. 그리고 코드를 올릴 때마다 보안 검사가 자동으로 돌게 만듦
  • 3차 — 내려받기 기능이 파일 전체를 한 번에 메모리에 올려서, 누군가 계속 내려받으면 서버가 멈출 수 있던 위험을 조금씩 흘려보내는 방식(스트리밍)으로 바꿈

매번 위험한 정도를 매겨 급한 것부터 고쳤고, 코드 자동 검사를 붙여 같은 문제가 다시 생기지 않게 했습니다.

남은 문제와 다음 할 일

  • 1차(사이트와 배포), 2차(가격 방식·화면 편집기) 계획은 끝났습니다. 3차(실제 결제 연결)는 아직 시작하지 않아 판매용으로는 미완성입니다.
  • 자료 저장소(데이터베이스)는 "개발 중엔 내 컴퓨터 → 출시할 땐 Oracle Cloud의 무료 서버"로 옮겨, 5년 동안 드는 비용을 최소로 하는 계획을 세워 두었습니다.
