소프트웨어 플랫폼

데모 링크 추가 예정 GitHub 링크 추가 예정

구독 기반으로 프로그램을 배포하고 관리하는, 실제로 접속해볼 수 있는 웹 서비스.

Main Features

  • 핵심 비즈니스 로직: 매달 결제 확인 → 끊기면 3회 경고 후 사용 차단 → 재구독 시 기존 데이터 복원
  • 제품별 가격 모델(무료/일회성/구독), GitHub Release와 연동해 안정/베타 채널 자동 분류 + 강제 업데이트 플래그
  • 관리자 비주얼 에디터 — 요소를 클릭해 속성 패널에서 바로 편집
  • 데스크톱 앱 연동 API(라이선스 검증, 최신 버전 조회, 사용 이벤트 수집)까지 구현
  • Vercel + Neon(PostgreSQL)으로 데모 환경 구축, 게스트 계정으로 실제 서비스 흐름 체험 가능

보안 감사 3차례

스스로 세 차례 보안 감사를 진행해 총 14건을 수정했다: 1차는 경로 탐색·로그인 무제한 시도·이메일 열거 등 7건, 2차는 헤더 인젝션·메모리 누수 등 3건(+ CI에 보안 검사 자동화 추가), 3차는 다운로드 API가 파일 전체를 메모리에 올려 생기는 서비스 거부 위험 등을 스트리밍 방식으로 교체. 매번 위험도를 매겨 우선순위대로 처리하고, CI에 정적분석을 편입시켜 재발을 막는 방식으로 진행했다.

Known Issues · Next Steps

  • 1차(사이트+배포), 2차(가격모델·인라인 에디터) 로드맵은 완료. 3차(실제 결제 연동)는 아직 미착수 — 상업적으로는 아직 미완성
  • 운영 DB는 "개발 단계 로컬 → 출시 시점 Oracle Cloud 무료 VM"으로 옮겨 5년 비용을 최소화하는 전략을 세워둠
