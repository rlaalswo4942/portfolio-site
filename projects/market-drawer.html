Market Drawer — 시사·주식 서랍 앱

GitHub 링크 추가 예정

세계 시사 정보와 국내 주식 데이터를 완전히 분리해서 수집하고, 최초 관측 후 168시간 이상 실데이터가 쌓여 조건을 통과한 종목에만 신호를 주는 Android 앱.

Main Features

  • 시사 서랍과 주식 서랍을 데이터 모델·API·알림 채널·탭까지 전부 분리
  • 최초 실측값 이후 168시간 미만이면 어떤 경우에도 추천 금지 — 결측치 임의 보간, 과거 데이터 소급 생성 금지
  • 실거래 대신 페이퍼 트레이딩으로 수익 거래 10회를 통과해야 복리 재투자 잠금 해제
  • GitHub Actions로 매시간 자동 수집, FCM data-only 푸시로 서버·클라이언트 알림 동기화
  • AI는 기사·공시 요약에만 사용하고 최종 추천 점수는 결정론적 규칙 엔진이 계산
  • 모의투자 전략 두 가지 — "칼"(168시간 검증 종목 중기 복리)과 "메스"(저가주 15분 눌림 단타, 시드 5만원, 장 마감 전 강제 청산)
  • 실제 거래비용 반영: 국내는 1틱 슬리피지·수수료·매도세, 미국은 수수료·환전 스프레드까지 차감한 가격으로 체결

레드팀 리뷰 5라운드

요구사항 충실도·데이터 무결성·신뢰성·UX·유지보수성 5개 축으로 스스로를 5라운드 검수했다. 1라운드는 78/100 — 샘플이 희박해도 시간만 지나면 통과되거나, 매도가 추천 이력 없이도 일어날 수 있었다. 최소 샘플·거래일 조건을 추가하고 진입/이탈 임계값을 분리(히스테리시스)해 5라운드 모두 100/100을 받았다. 복리 재투자 규칙도 "수익 거래 10회 달성 시 해제"로 시작했다가, "포트폴리오가 주간 10회 넘게 원금 아래로 떨어지면 복리를 끄고 고정 사이즈로 되돌아간다"는 리스크 기반 규칙으로 다시 정의했다 — 드로다운이 잦다는 것 자체가 전략이 재투자 자금을 맡기기엔 불안정하다는 뜻이라는 게 코드 주석에 남아있다.

모의투자 검증 단계 (2026-10)

칼은 거래비용 없이 돌린 사이클을 끝낸 뒤, 같은 시점·같은 관측 가격으로 비용을 넣어 다시 계산하고 비용 반영 테스트 3사이클을 통과해야만 20만원 연속 복리 운용으로 넘어가게 했다. 첫 실행을 분석해 보니(10-12) 칼은 손절 없이 하락장을 버텼고, 메스의 -0.5% 눌림 진입은 무작위 진입보다 나을 게 없었다. 그래서 "규칙 세트 2"로 시장 국면 필터·손절·추적 청산을 넣은 방어형과, 모멘텀·돌파 기반 공격형을 같은 시드·같은 시점에 나란히 출발시켜 비교한다 — 비교 결과도 168시간과 최소 표본 조건을 채우기 전에는 보여주지 않는다. 15분 동기화 사이에는 실제 1분봉을 재생해 손절·익절을 분 단위로 판정하도록 바꿨고, 실제 10-06~08 데이터로 공격형 메스 손절이 -1.2% 기준에 평균 -1.24%로 체결되는 것을 확인했다.
