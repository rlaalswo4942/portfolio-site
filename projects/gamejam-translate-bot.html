무엇인가요

언어별 대화방에 글을 번역해 옮겨 주는 자동 프로그램입니다.

왜 만들었나요

여러 나라 사람이 모인 게임잼에서 말이 통하게 하려고 만들었습니다.

어떻게 움직였나요

한국어로 쓰면 다른 언어 방에 같은 이름으로 번역돼 올라갔습니다.

지금 상태 · 작동 안 함

지금은 멈춰 있어서 다시 살릴 예정입니다.

기능 자세히
  • 언어별 채널 자동 생성: 한국어, 일본어, 중국어(간체·번체), 네덜란드어, 영어
  • 원래 글쓴이의 이름과 프로필 사진을 그대로 살려 번역 글 전달(웹훅 사용)
  • 무료 번역 서비스(MyMemory)로 자동 번역
  • 초대용 QR코드 만들기 기능
남은 문제와 다음 할 일
  • 지금은 작동하지 않습니다. 봇을 올려 두던 서버 서비스(Railway)에 자리는 남아 있지만 실행이 내려간 상태입니다.
  • 다시 작동하도록 고칠 예정입니다.
어려운 말 풀이
게임잼
짧은 기간 안에 게임을 만드는 대회·행사.

API
다른 서비스의 기능을 빌려 쓰는 창구.
배포
