Main Features

  • 언어별(ko/ja/zh-cn/zh-tw/nl/en) 채널 자동 생성
  • 웹훅으로 이름·아바타를 유지한 채 메시지 중계
  • MyMemory 무료 번역 API로 자동 번역
  • QR코드 초대 생성 기능 포함
