디스코드 봇 · 2026 · 작동 안함

게임잼 번역 중계 봇

GitHub 링크 추가 예정

여러 나라 사람이 모인 게임잼 디스코드에서, 한국어로 쓴 글이 다른 언어 채널에는 자동으로 번역돼 올라가게 해 주던 봇입니다. 지금은 작동하지 않는 상태입니다.

한눈에 보기

무엇인가요

디스코드(단체 채팅 앱)에 언어별 채널을 만들어 두고, 한 채널에 쓴 글을 다른 언어 채널로 번역해 옮겨 주는 자동 프로그램(봇)입니다.

왜 만들었나요

다국어 게임잼 행사에서, 서로 쓰는 언어가 달라도 같은 대화를 나눌 수 있게 하려고 만들었습니다.

어떻게 움직였나요

예를 들어 한국어 채널에 글을 쓰면, 일본어·중국어·네덜란드어·영어 채널에 각 언어로 번역된 글이 쓴 사람의 이름과 프로필 사진 그대로 올라갔습니다.

지금 상태 · 작동 안 함

봇을 올려 두던 서버(Railway)에서 실행이 내려간 것을 확인했고, 다시 살릴 예정입니다.

주요 기능

  • 언어별 채널 자동 생성: 한국어, 일본어, 중국어(간체·번체), 네덜란드어, 영어
  • 원래 글쓴이의 이름과 프로필 사진을 그대로 살려 번역 글 전달(웹훅 사용)
  • 무료 번역 서비스(MyMemory)로 자동 번역
  • 초대용 QR코드 만들기 기능

남은 문제와 다음 할 일

  • 지금은 작동하지 않습니다. 봇을 올려 두던 서버 서비스(Railway)에 자리는 남아 있지만 실행이 내려간 상태입니다.
  • 다시 작동하도록 고칠 예정입니다.

어려운 말 풀이

게임잼
짧은 기간 안에 게임을 만드는 대회·행사.
봇
자동으로 글을 읽고 쓰는 프로그램 계정.
웹훅
다른 프로그램이 채널에 글을 대신 올릴 수 있게 해 주는 통로. 올리는 이름과 사진을 바꿀 수 있습니다.
API
다른 서비스의 기능을 빌려 쓰는 창구.
배포
만든 프로그램을 서버에 올려 실제로 돌아가게 하는 것.
