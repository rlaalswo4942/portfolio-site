한눈에 보기

무엇인가요

바이브코딩 수업 교재(워크북)를 장별로 정리해 올리고, 그 위에서 질문·답변·메모를 할 수 있게 만든 수업용 웹사이트입니다.

누가 쓰나요

같은 워크북으로 공부하는 사람들입니다. 모르는 문장을 표시해 물으면 다른 사람이 실시간으로 답할 수 있습니다.

어떻게 쓰나요

사이트에 들어가 이름만 정하면 바로 시작합니다. 본문을 드래그해 형광펜을 칠하고 질문을 남기면 됩니다. 비밀번호는 없습니다.

지금 상태 · 운영 중

위의 '사이트' 버튼으로 바로 들어가 볼 수 있습니다.

주요 기능

  • 워크북 문서 18개를 장별 안내로 정리. 실습 단계(Step) 78개마다 "어디서(13곳 중 어느 화면에서) · 어떻게 · 무엇이 보이면 성공인지"를 알려 주는 작업 지도
  • 본문을 드래그해 형광펜·메모지로 표시하고 질문. 위쪽 표시 칩과 왼쪽 목차에 색으로 나타나 바로 이동
  • 질문·답변·표시가 모든 사람 화면에 실시간으로 공유(Supabase Realtime). 다시 연결될 때마다 서버와 맞춰 빠진 것이 없게 함
  • 이름 = 내 아이디(비밀번호·인원 제한 없음). 같은 이름이면 어느 기기에서든 내 글로 알아보고, 내 글만 고치고 지울 수 있음
  • 장별 메모장과 '나만 보기' 표시는 내 아이디 공간에만 저장. 서버가 비밀 확인값을 검사한 뒤에만 읽고 씀
  • 참가자가 자기 GitHub 저장소·배포 주소를 올리고 서로 찾아볼 수 있는 저장소 모음
  • 원본 워크북에서 장별 자료를 다시 만들어 내는 자동 스크립트와 Step 개수 검사 스크립트. 공개본에서는 체크 표시를 초기화

남은 문제와 다음 할 일

  • 비밀번호가 없어서 이름을 아는 사람은 그 이름으로 들어올 수 있습니다. 그래서 입력 화면에서 "이름+숫자"처럼 쓰기를 권합니다.
  • 개인 메모는 가장 최근 저장이 이기는 방식이라, 두 기기에서 동시에 고치면 나중에 저장한 것만 남습니다.
  • 표시를 빠르게 연속으로 바꿀 때 생기던 충돌과, 설정을 다시 실행할 때 실시간 기능이 중복 등록되던 오류(42710)는 고쳤습니다. 사용자가 많아지면 관리용 삭제 기능을 관리 화면 밖으로 옮길 필요가 있습니다.

어려운 말 풀이

워크북
수업에서 따라 하며 실습하는 교재.
실시간(Realtime)
새로고침하지 않아도 다른 사람의 변화가 바로 내 화면에 나타나는 것.
Supabase
데이터베이스·로그인·실시간 기능을 빌려 주는 온라인 서비스.
해시
원래 값을 알아볼 수 없게 바꾼 확인용 값.
권한 설계(RLS)
누가 어떤 자료를 읽고 쓸 수 있는지 규칙으로 정하는 것.
스크립트
반복 작업을 자동으로 처리하는 짧은 프로그램.
E2E 테스트
실제 사용자처럼 브라우저를 움직여 처음부터 끝까지 확인하는 자동 검사(Playwright 사용).
