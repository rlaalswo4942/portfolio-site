바이브코딩 워크북 Q&A

GitHub ↗ 사이트 ↗

궁금한 문장에 바로 형광펜을 긋고 질문한다 — 질문은 같은 워크북을 보는 사람들과 실시간으로 나누고, 메모는 나만 본다.

Main Features

  • 워크북 18개 문서를 장별 가이드로 정리하고, 실습 Step 78개마다 "어디서(13개 장소) · 어떻게 · 무엇이 보이면 성공"을 안내하는 작업 지도
  • 본문을 드래그해 형광펜·메모지로 마킹하고 질문 — 상단 칩과 좌측 트리에 색으로 표시돼 바로 이동
  • Supabase Realtime으로 질문·답변·마킹이 실시간 공유되고, 연결될 때마다 서버와 다시 동기화
  • 이름 = 고유 아이디(비밀번호·인원 제한 없음) — 같은 이름이면 어느 기기에서든 내 글로 인식하고 본인 글만 수정·삭제
  • 장별 메모장과 "나만 보기" 마킹은 아이디 공간에만 저장 — 서버 함수가 비밀 해시를 확인한 뒤에만 읽고 씀
  • 참가자가 자기 GitHub 저장소·배포 링크를 제출하고 검색하는 저장소 폴더
  • 원본 워크북에서 장별 데이터를 다시 만드는 빌드 스크립트 + Step 개수 검사 스크립트 — 공개본에서는 체크 표시 초기화

Known Issues · Next Steps

  • 비밀번호가 없어 이름을 아는 사람은 그 이름으로 들어올 수 있음 — 입력 화면에서 "이름+숫자"를 권장
  • 개인 메모는 최신값 우선이라 두 기기에서 동시에 편집하면 나중 것이 남음
  • 마킹 연속 변경 경합과 SQL 재실행 시 realtime 중복 등록 에러(42710)는 수정함 — 실사용 규모가 커지면 관리용 삭제를 대시보드 밖으로 옮길 필요가 있음
