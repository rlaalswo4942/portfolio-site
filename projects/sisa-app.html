시사 서랍

GitHub 링크 추가 예정

하루 종일 뉴스를 들여다보지 않아도, 안 읽은 것만 하루 세 번 정리해서 알려준다 — 실제 갤럭시 S22에서 매일 쓰는 중이다.

Main Features

  • Market Drawer에서 주식 서랍을 걷어내고 시사 서랍만 남긴 포크
  • 매시간 세계 뉴스를 자동 수집, Gemini로 기사 요약
  • 하루 세 번(오전 7시·낮 12시·저녁 6시) 안 읽은 기사만 모아 알림 발송 — 새 소식 없으면 알림도 안 보냄
  • PC를 켜두지 않아도 완전히 자동으로 동작 (아래 참고)

PC 없이 돌아가게 만들기

처음엔 PC에서 서버·스케줄러·터널 프로그램 3개를 계속 띄워둬야 했고, 실제로 아침 7시 브리핑을 한 번 놓친 사고가 있었다. 그래서 전체를 Cloudflare Workers + D1(서버리스 SQLite)으로 옮겼는데, 이 샌드박스 환경에서만 겪는 문제들이 이어졌다: 암호화 라이브러리가 아예 작동하지 않아 푸시 인증에 필요한 서명을 표준 라이브러리만으로 직접 구현해야 했고, 요청 하나당 처리 가능한 작업 수 제한 때문에 대량 삽입 로직을 다시 짰고, Google이 Cloudflare의 공유 IP 대역 자체를 차단하고 있어서 뉴스 수집과 AI 요약은 결국 GitHub Actions 쪽으로 옮겼다. 지금은 "수집·요약은 GitHub Actions, 조회·알림·크론은 Cloudflare Worker"로 역할을 나눠 PC 없이도 완전 자동으로 돈다.
