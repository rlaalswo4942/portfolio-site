전주대 생활권 혼잡도 지도

배포 사이트 보기 ↗ 저장소는 팀 비공개(JJPG-team) — 공개 링크 추가 예정

"전주대 생활권에서 지금 어디가 붐비고, 어디가 한산할까?" — 통신사·GPS·공공센서 3소스 가중합으로 구역별 혼잡도 점수를 계산해 4단계로 표시한다. 상권 검색과 길찾기는 9월부터 실제 데이터(Kakao Local API·OSRM)로 전환했다.

Main Features

  • 지도에서 장소 탐색 + 구역 혼잡도 확인
  • 장소명·메뉴 검색, 카테고리 필터 — 9월부터 Kakao Local API로 실제 상호·좌표·업종 조회 (Cloudflare Pages Function으로 프록시해 키 비노출)
  • 도보 경로는 FOSSGIS OSRM 보행자 프로파일로 실제 계산 — 공개 데모 서버의 도보 경로가 사실은 차량 경로와 동일했다는 걸 발견하고 실제 보행자 서버로 교체
  • 혼잡도·시간표 기반 방문 장소 추천, 강의동은 추천 후보에서 제외
  • 시간표는 색상·격자 기반 자체 판독 + 과목명만 부분 OCR(tesseract.js)
  • Capacitor 기반 안드로이드 앱도 병행 개발 (배포 웹을 그대로 로드하는 방식이라 웹 업데이트가 곧 앱 업데이트)

Data · Method · Validation · Limitation

Data

상권 위치·검색은 Kakao Local API 실데이터 전환 완료. 혼잡도 6블록 지표(통신사·GPS·공공센서)는 여전히 시나리오 기반 Mock — 화면에 "시연" 배지로 명시

Method

혼잡도: 3소스 가중합(50/30/20%) → 0~100점 → 4단계 분류. 경로: 실 API 실패 시 Mock으로 자동 폴백하는 Provider 패턴

Validation

외부 레드팀 리뷰로 취약점 5건 식별 후 수정 — 인증 비교를 타이밍 공격에 안전한 방식으로 교체, 프록시 캐싱으로 무료 쿼터 소모 절감, 입력값 검증 추가

Limitation

혼잡도 지표는 여전히 Mock · 배포 환경에 Kakao API 키가 실제 설정돼 있는지는 대시보드 확인 필요(코드 조사만으론 불확실)

Known Issues · Next Steps

  • 가짜 상호 15곳을 발견해 전부 삭제하고, OSM 대조·역지오코딩·팀 상권조사로 검증된 곳만 단계적으로 추가 — 좌표를 못 믿을 상호는 지어내지 않고 보류
  • 보행 경로가 건물을 뚫고 지나가는 문제를 두 번 겪음: ①공개 OSRM 서버가 실은 차량 경로를 주고 있었던 문제, ②마지막 구간을 직선으로 이어붙여 벽을 관통하던 문제 — 각각 실제 보행자 서버 교체, 벽 충돌 지점에서 선을 끊는 방식으로 해결
  • 지도 타일 정책이 두 번 바뀌어(OSM 표준→CARTO 무료→다시 OSM 표준) 왔다갔다한 이력 있음
