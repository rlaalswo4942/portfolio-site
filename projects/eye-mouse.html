시선 마우스

GitHub 링크 추가 예정

손을 쓰지 않고, 눈으로 보고 깜빡여서 누른다 — 일반 웹캠 하나로 만드는 마우스 대체 프로그램.

Main Features

  • MediaPipe Face Landmarker로 얼굴 점 478개를 읽어 홍채 위치·눈 방향·머리 각도 등 특징 20개로 줄이고, 모니터별 릿지 회귀로 화면 좌표를 예측
  • 마우스를 못 쓰는 상황을 상정해 로그인 시 대기 상태로 자동 시작 — 웹캠 쪽을 보고 눈을 1초 감았다 뜨면 켜지고 꺼짐
  • 클릭은 누를 곳을 보고 두 번 깜빡이기. Windows UI Automation으로 근처 버튼에 맞춰 붙고(스냅), 커서를 움직이지 않고 누를 수 있어 실제 마우스와 따로 동작
  • 보정: 화면 끝까지 퍼진 점 16개를 시선이 실제로 도착해 머물 때만 기록, 단계 사이 쉬는 시간과 효과음 안내. 웹캠이 조금 움직였을 때는 점 5개짜리 빠른 재조정
  • 듀얼 모니터 지원(화면별 모델 + 어느 화면을 보는지 판별), One Euro 필터로 떨림 보정
  • 외부 API 없이 PC 안에서만 동작, 화면 없는 논리 시험 54개·가짜 시선으로 실제 창을 누르는 전체 흐름 시험 42개

Known Issues · Next Steps

  • 실측 보정 오차는 정면 모니터 약 100~250px, 옆 모니터 약 400~585px — 아직 작은 버튼을 바로 누르기엔 부족해 스냅으로 보완하는 중
  • 저가 웹캠(640×480, 초당 15~19장)이 병목이고, 모니터 위에 달려 있어 화면 아래쪽을 보면 눈이 감긴 것처럼 찍힘 → 깜빡임을 고정 기준이 아닌 "최근 1.2초 대비 급변"으로 판정하도록 바꿈
  • Windows 커서는 하나뿐이라 진짜 두 번째 커서는 불가 — 시선 포인터는 화면 표시로만 존재
  • 다음: 끌기·스크롤·오른쪽 클릭 추가, 실측 오차에 맞춘 스냅 반경 조정
