STT — 실시간 음성변환

GitHub 링크 추가 예정

컴퓨터로 들리는 소리(내 목소리, 유튜브 영상 소리)를 실시간으로 받아 적는 프로그램입니다. 받아 적기는 되지만 아직 정확도가 만족스럽지 않아 계속 다듬고 있습니다.

한눈에 보기

무엇인가요

마이크로 들어오는 내 목소리와 스피커로 나가는 컴퓨터 소리(영상·방송·통화)를 동시에 듣고, 그 자리에서 글자로 바꿔 주는 프로그램입니다. 자동 자막이나 회의록을 떠올리면 쉽습니다.

어디에 쓰나요

음성 비서 Pia가 사람 말을 알아듣는 '귀' 역할을 하도록 만든 부품입니다. 받아 적은 결과는 중앙 데이터베이스에 쌓여 Pia를 가르치는 자료로도 쓰입니다.

어떻게 움직이나요

소리를 받음 → 글자로 바꿈 → 녹음이 끝나면 결과가 맞는지 스스로 다시 확인하고, 미심쩍으면 AI로 고침 → 외국어면 한국어 번역도 함께 저장.

지금 상태 · 진행 중

받아 적기 자체는 성공했지만, 실제로 써 보면 틀리는 부분이 많아 정확도를 높이는 방법을 찾고 있습니다.

주요 기능

  • 두 소리를 동시에 — 마이크 소리와 컴퓨터에서 나가는 소리를 함께 받습니다. 스피커 소리를 마이크로 다시 녹음하는 게 아니라 컴퓨터 안에서 곧바로 가져오기(WASAPI 루프백) 때문에 깨끗하게 받을 수 있습니다.
  • 실시간 받아 적기 — 말하는 동안 바로바로 글자로 바뀝니다(faster-whisper 사용).
  • 스스로 채점하기 — 녹음이 끝나면 받아 적은 글을 다시 목소리로 만들고 → 그걸 또 받아 적어 → 처음 글과 얼마나 같은지 비교합니다. 일치율이 낮으면 내 컴퓨터 속 AI(Ollama)가 문장을 고쳐 줍니다.
  • 외국어 자동 번역 — 외국어로 말한 부분은 한국어 번역을 함께 저장합니다.
  • 다른 프로그램에서도 재사용 — Pia의 '듣기' 부분으로 그대로 가져다 쓸 수 있게 만들었고, 결과는 중앙 데이터베이스에 쌓입니다.

"제대로 받아 적었나"를 확인하는 방법 찾기

처음에는 원래 녹음과, 받아 적은 글을 다시 읽힌 소리를 '소리 모양(파형)'끼리 비교해 정확도를 재려고 했습니다. 그런데 실제로 재 보니 내용이 완전히 다른 문장끼리도 97% 넘게 비슷하다고 나왔습니다. 소리 모양만 봐서는 내용이 맞는지 알 수 없다는 뜻이었습니다.

그래서 비교 대상을 소리가 아니라 글자로 바꿨습니다. "글자 → 목소리로 다시 만들기 → 다시 받아 적기 → 글자"로 한 바퀴 돌려 처음 글과 비교하는 방식입니다. 예전 방식으로 되돌아가지 말자는 원칙도 기록해 두었습니다.

또 연결된 오디오 장치를 하나씩 차례로 찾다 보니, 장치 하나가 느리면 전체가 멈췄습니다. 여러 장치를 동시에 찾도록 바꿔 2초 안에 끝나게 했습니다.

남은 문제와 다음 할 일

  • 컴퓨터에서 재생되는 영상 소리나 마이크 목소리를 글자로 바꾸는 것 자체는 성공했지만, 실제로 써 보면 정확도가 아직 아쉽습니다.
  • 정확도를 높이는 방법을 계속 찾고 있습니다.
