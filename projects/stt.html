STT — 실시간 음성변환

GitHub 링크 추가 예정

마이크와 시스템 오디오를 동시에 캡처해 실시간으로 텍스트로 바꾼다 — 다만 정확도는 아직 만족스럽지 않다.

Main Features

  • 마이크와 시스템 오디오(WASAPI 루프백)를 동시 캡처 — 유튜브·스트리밍처럼 스피커로 나가는 소리도 재입력 없이 직접 캡처
  • faster-whisper 기반 실시간 음성-텍스트 변환
  • 녹음 종료 후 후처리 파이프라인이 자동 검증: 인식된 텍스트를 다시 음성으로 합성 → 재인식 → 원문과 일치율 계산 → 낮으면 로컬 LLM(Ollama)으로 보정
  • 외국어 발화는 자동으로 한국어 번역을 함께 저장
  • Pia의 입력 파이프라인으로 재사용 가능하게 설계, 결과는 중앙 DB에 축적

검증 방법에 대한 발견

처음엔 원음 파형끼리 직접 비교(MFCC/DTW)해서 인식 정확도를 검증하려 했는데, 내용이 완전히 달라도 유사도가 97% 이상 나온다는 걸 실측으로 확인했다 — 파형 비교 자체가 검증 수단으로 무의미하다는 뜻이다. 그래서 "텍스트→음성 재합성→재인식→텍스트"로 왕복시켜 비교하는 방식으로 바꿨고, "이 방식으로 되돌아가지 말 것"이라고 원칙으로 남겨뒀다. 오디오 장치 탐지도 처음엔 순차 탐색이라 장치 하나가 느리면 전체가 멈췄는데, 병렬 탐지로 바꿔 2초 안에 끝나게 만들었다.

Known Issues · Next Steps

  • PC에서 재생 중인 영상 음성이나 마이크로 입력되는 음성을 텍스트화하는 것 자체는 성공했으나, 체감 정확도가 아직 만족스럽지 않은 편
  • 인식 정확도를 높이는 방법을 계속 모색 중
