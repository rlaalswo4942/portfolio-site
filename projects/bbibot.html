삐봇 — 바탕화면 정리 캐릭터

Microsoft Store에서 받기 ↗ 개인정보 처리방침 ↗

어지러운 바탕화면을 귀찮은 정리 작업 대신, 작은 공 로봇이 파일을 하나씩 날라 치워 주는 모습을 구경하는 일로 바꾼 Windows 앱.

Main Features

  • 파일 정리: 바탕화면 아이콘을 바구니에 넣으면 삐봇이 직접 들고 가서 종류별 폴더에 정리
  • 한 번에 정리: 처음 실행할 때 동의하면 바탕화면 전체를 한 번에 정리하고, 원하면 한 번에 원래대로 되돌림
  • 되돌리기: 종을 누르거나 채팅바에 "가져와"라고 쓰면 정리한 파일을 원래 자리로 다시 가져다줌
  • 관리 창: 정리한 파일을 이름으로 찾아 열기, 원래 자리로 되돌리기, 바탕화면으로 가져오기
  • 캐릭터와 놀기: 마우스로 잡아서 옮기거나 매달 수 있고, 아이콘을 끌고 다가가면 도망가고, 종을 계속 누르면 지쳐서 머리를 감쌈
  • 채팅바 명령: 밥·사다리 같은 물건을 불러낼 수 있고, 밥을 많이 먹으면 커지다가 분신으로 나뉨
  • 안심하고 쓰기: 파일을 지우거나 덮어쓰지 않고, 파일 내용을 읽지 않으며, 어떤 정보도 PC 밖으로 보내지 않음
