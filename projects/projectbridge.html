GitHub 링크 추가 예정

코드가 아니라 "어디까지 했고, 무엇을 정했고, 다음에 뭘 할지"를 여러 컴퓨터 사이에 이어 주는 도구입니다.

한눈에 보기

무엇인가요

AI 코딩 도우미 Claude Code에 붙여 쓰는 추가 기능(플러그인)입니다. 작업 메모를 GitHub에 올려 두고, 다른 컴퓨터에서 그대로 이어받게 해 줍니다.

왜 필요한가요

집 컴퓨터와 노트북을 오가며 일하면 코드는 옮겨져도 "왜 이렇게 했는지, 다음에 뭘 할지" 같은 맥락은 사라집니다. AI 도우미도 새 컴퓨터에서는 이전 대화를 모릅니다.

어떻게 쓰나요

짧은 명령어를 입력합니다. 작업 중간에는 checkpoint(중간 저장), 자리를 뜰 때는 handoff(넘겨주기), 다른 컴퓨터에서는 takeover(이어받기)를 씁니다.

지금 상태 · v1.0.0 배포됨

첫 정식 버전(1.0.0)을 내놓았습니다.

주요 기능

  • 결정사항·할 일 목록(TODO)·인수인계 메모 같은 작업 맥락을 GitHub로 동기화
  • 짧은 명령어 제공: init(처음 설정), start(작업 시작), checkpoint(중간 저장), handoff(넘겨주기), takeover(이어받기), status(현재 상태 보기)
  • 실수 방지 장치: 저장소의 기존 기록을 덮어쓰는 '강제 올리기' 금지, 폴더 안 파일을 한꺼번에 몽땅 올리기(git add -A) 금지
  • 올리기 전에 비밀번호·열쇠 같은 비밀 정보가 섞였는지 자동 검사
  • 두 컴퓨터가 동시에 기록을 고치지 않도록 잠금: "내가 마지막으로 본 상태와 같을 때만 고친다"(compare-and-swap) 방식
