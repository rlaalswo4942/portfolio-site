[준비물]
- 컴퓨터(Windows 10/11 또는 Mac)와 인터넷 연결
- Claude 계정 + 유료 플랜(Pro 이상) 또는 API 결제 — 무료 계정으로는 Claude Code를 쓸 수 없습니다.
- (GitHub에 올릴 때) GitHub 계정 — 미리 github.com에서 가입해두면 편합니다.

[시작하기 전에]
0. 압축을 반드시 먼저 풀어주세요. (오른쪽 클릭 > 압축 풀기 / 전체 압축 풀기)
   압축을 풀지 않고 zip 안에서 바로 실행하면 파일을 못 찾거나 실패할 수 있습니다.
1. 자세한 설명이 필요하면 "Claude Code + VSCode 설치 가이드.pdf"를 먼저 읽어보세요.
   (이 폴더의 프로그램은 그 가이드의 과정을 최대한 자동으로 대신해줍니다.)

[Windows 사용자]
1. "Windows" 폴더 안의 "실행.bat"을 더블클릭하세요.
2. (처음 한 번만) Git, VS Code, Claude Code, VS Code 확장(Claude Code, Live Server)이
   자동으로 설치됩니다. 몇 분 걸릴 수 있어요.
   - 중간에 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 "예"를 눌러주세요.
3. GitHub 가입 이메일을 물어보면 입력하고 엔터, 아직 계정이 없으면 그냥 엔터를 누르세요.
4. 준비가 끝나면 VS Code 창과 검은 화면(Claude)이 자동으로 열립니다.
   - 작업 폴더는 "문서\vibe-coding" 입니다.
   - 검은 화면에 나오는 안내를 따라 브라우저에서 로그인해주세요.
5. 로그인이 끝나고 Claude 대화창이 뜨면 Ctrl+V를 눌러
   미리 복사해둔 설정 문구를 붙여넣고 엔터를 누르세요.
   (내용은 "프롬프트.txt"에 있으며, 필요하면 직접 열어서 수정해도 됩니다.)
- 다음에 다시 켤 때는 "실행.bat"만 누르면 설치 과정 없이 바로 열립니다.

[Mac 사용자]
1. VS Code는 자동 설치가 안 되므로, PDF 가이드의 1단계대로 먼저 직접 설치해주세요.
   (VS Code를 연 뒤 Cmd+Shift+P > "Shell Command: Install 'code' command in PATH" 실행)
2. "Mac" 폴더 안의 "Claude Code 자동설정 (Mac).command"를 더블클릭하세요.
   - 처음 한 번은 파인더에서 오른쪽 클릭 > 열기를 눌러야 실행이 허용됩니다.
   - 터미널에서 실행 권한이 없다는 오류가 나오면 아래 명령을 한 번만 실행하세요:
     chmod +x "Claude Code 자동설정 (Mac).command"
   - "명령어 라인 개발자 도구를 설치하겠습니까?" 창이 뜨면 "설치"를 누르세요. (Git 설치)
3. Claude Code와 확장이 설치되고, VS Code가 "문서/vibe-coding" 폴더로 열립니다.
   설정용 프롬프트는 클립보드에 복사됩니다.
4. 왼쪽 사이드바의 Claude 아이콘을 눌러 로그인한 뒤, 대화창에 Cmd+V로 붙여넣고 엔터를 누르세요.

[공통 안내]
그 다음부터 만들고 싶은 프로그램이나 웹사이트를 자연어로 설명하면
Claude가 코드를 작성하고 실행까지 도와줍니다. (바이브 코딩)

[안 될 때]
- "winget이 없습니다" 메시지가 뜨면(Windows), Microsoft Store에서 "앱 설치 관리자"를
  업데이트한 뒤 "실행.bat"을 다시 눌러주세요.
- "Windows에서 PC를 보호했습니다"라는 파란 창이 뜨면, "추가 정보 > 실행"을 눌러주세요.
  (인터넷에서 받은 새 프로그램이라 나오는 정상적인 경고입니다)
- "설치되지 않은 프로그램: ..." 이 빨간 글씨로 나오면(Windows), 인터넷 연결을 확인하고
  "실행.bat"을 다시 누르세요. 그래도 안 되면 컴퓨터를 재시작한 뒤 다시 실행하세요.
- 자세한 문제 해결은 PDF 가이드 마지막 페이지의 "문제 해결" 표를 참고하세요.
- 인터넷 연결이 필요합니다.
- 그래도 해결이 안 되면, 실행.bat 옆에 생기는 "설치기록.txt" 파일을
  알려준 사람에게 보내주세요. 어디서 멈췄는지 확인할 수 있습니다.
